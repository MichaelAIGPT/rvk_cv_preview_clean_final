Технологический стек и модели

Каскадная архитектура и используемые технологии

Вместо тяжелых монолитных нейросетей применен каскад специализированных легковесных моделей:

1. Полнокадровый детектор: YOLOX-S Apache 2.0
  • • Сканирует полный кадр 1080p, детектирует силуэты персонала.
  • • Скорость инференса: 25–35 мс на GPU / 65–90 мс на CPU.
  • • Формат поставки: ONNX Runtime без тяжелых зависимостей.
2. Классификатор СИЗ: MobileNetV3-Small Accuracy 98.4%
  • • Микросеть для бинарной оценки каски (голова) и жилета (тело).
  • • Скорость инференса: 0.79 мс на 1 силуэт на обычном CPU!
  • • Пропускная способность: ~1 270 силуэтов в секунду.
3. Двудольный Bipartite IoU-трекер Венгерский алгоритм
  • • Устранение разрывов траекторий при проходе за насосами и трубами.
  • • Жесткий порог перекрытия IoU ≥ 0.3 исключает скачки ID.
  • • Скользящее окно памяти 10 кадров восстанавливает трек после затенения.
4. Геометрический модуль (Shapely) Point-in-Polygon
  • • Проверка нахождения человека в полигоне по точке опоры ног.
  • • Временное окно подтверждения тревоги: 8 из 10 кадров (5 секунд).
  • • Cooldown 60 секунд предотвращает спам в журнале инцидентов.

Сквозная архитектура: От RTSP до PostgreSQL, MinIO и 1С/SCADA

Модульная микросервисная архитектура без жестких привязок: от локального автономного MVP до отказоустойчивого Docker-кластера в ЦОД.

1. Видеопоток RTSP / ONVIF
  • • IP-камеры цеха (1080p, H.264 / H.265).
  • • Асинхронный декодер OpenCV / GStreamer.
  • • Буферизация кадров и кольцевой FIFO кэш.
  • • Автореконнект при сбоях сетевого канала.
2. CV-Ядро Каскад
  • • YOLOX-S (ONNX): силуэты (25–35 мс).
  • • Crop Slicer: запас контекста +15%.
  • • MobileNetV3: каски и жилеты (0.79 мс).
  • • Shapely: опасные зоны насосов.
  • • IoU Tracker: сглаживание 8/10 кадров.
3. Базы данных СУБД / S3
  • • MVP: JSON/YAML с атомарной записью (ACID-safe, <1 мс, 0 зависимостей).
  • • Prod (Docker): PostgreSQL 15+ (инциденты, смены, RBAC, аудит).
  • • MinIO S3: стоп-кадры и Full HD кропы.
  • • Redis: очереди алертов и сессии.
4. Интеграции REST / OpenAPI
  • • FastAPI ASGI (Swagger OpenAPI 3.0).
  • • 1С:ERP / 1С:Охрана труда: выгрузка нарушений и табельных карточек.
  • • АСУ ТП / SCADA: Webhooks & OPC UA.
  • • Telegram Bot / Email: пуши диспетчерам.

🏆 Почему EfficientNet-B0 — лучшая:

Архитектура Compound Scaling одновременно масштабирует глубину, ширину и разрешение. Она лучше всех улавливает мелкие текстуры (ремешки каски, козырек, светоотражающие полосы) на фоне насосов и труб. 0 пропусков (FN=0) при скорости 16 мс на GPU (~60 FPS).

⚡ MobileNetV3 — чемпион для CPU:

Весит всего 7.6 МБ (в 4 раза легче EfficientNet и в 11 раз легче ResNet). Время инференса на обычном офисном процессоре — всего 9.8 мс. Идеальный резерв для развертывания на серверах без дискретной видеокарты.

🔬 Почему ResNet-18 уступил:

Несмотря на высокую параллельную скорость на GPU (5 мс), модель тяжелая (85.7 МБ) и на контрольной выборке допустила 1 пропуск нарушения (Recall упал до 83.3%), перепутав сложный смазанный ракурс на лестнице цеха.
